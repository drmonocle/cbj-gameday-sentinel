# v1.4.1 - Spoiler, Delay & Shot Chart Fixes
## CBJ Gameday Sentinel v1.4.1

A fixes release from a full code audit. No new screens; the Shots tab, stream delay, and spoiler mode now behave the way the README promises.

### Fixes
- **Stream delay now covers the live shot chart.** Goals no longer show up on the Shots tab ahead of your delayed stream.
- **Spoiler mode now hides the Shots tab** until you click *Reveal*, like Games, Standings, and News.
- **Shot charts are more accurate.** Shots are oriented by which end each team is defending (it flips every period) instead of mirroring by position, so long shots from your own half are no longer drawn as close-range shots. Shootout attempts are excluded and own-half shots are no longer plotted on the offensive-zone rink.
- **Season heatmap counts regular-season and playoff games only** (preseason is excluded).
- **A failed shot-chart download no longer sticks.** It retries after a minute instead of showing an empty chart until you restart. The season download is also throttled to be gentler on the NHL servers.

### Other changes
- **The team logo is no longer bundled in the app or the repository.** The app downloads it on first launch and shows a generic icon until then.
- **Forks for the other 31 teams** now use their own team name in alerts and settings, and only show news sources that exist for them. Fixed several team preset values (ESPN IDs for DAL/EDM/LAK, ESPN logo names for NJD/TBL/SJS/LAK, the Ottawa subreddit, Utah's name).
- Automated tests now run on every push, and releases are built by GitHub Actions.
- `SECURITY.md` updated to match what the app actually fetches and writes.

> **Note on Windows SmartScreen**: the exe is unsigned, so Windows may warn the first time you run it. Click **More info → Run anyway**, or run from source.
